claude-chats

how it works
chats
Type a name → start. Click any chat to resume it. Each one is just a folder in ~/claude-chats.
panes
1 2 3 4 split the screen. Click a pane to focus it — the next chat you open takes that pane.
status dot
running  ·  finished, wants you
drop in files
Drag a file or folder onto a session — its real path gets typed in.
keys
⌘1–⌘4 layout   ⌘0 this list
⌘⇧[ ⌘⇧] switch pane
⌘F find in session, ↑↓ to step
sound
🔔 up top plays a chime when a session finishes.
